# TasteBuilder v2

A techy, animated school for video taste: attention graphs, story arcs, platform signals, and the director's eye. No editing software required.

- Next.js 16.4.3, App Router, React 19.3, Tailwind CSS v4
- 3 phases, 9 Acts, 36 lessons, each in 6 numbered steps: Concept, Brain, Good vs Weak, Rep, Self-check, Takeaway
- 4 interactive Taste Labs, with animated retention graphs
- Fonts: Space Grotesk + Manrope + JetBrains Mono
- Palette: deep tech black #05070B, signal cyan #00E5FF, acid lime #C8FF2E sparingly, pink #FF5C7A only for weak versions
- Sources are separated into Research, Platform, and Practice on /sources

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
